Étape 1 : Ajouter Playlist M3U
  1. Ouvrir Perfect Player
  2. Menu ⊙ → Playlist
  3. Clic droit → Add
  4. Coller URL M3U :
     https://raw.githubusercontent.com/rave-creator/French-IPTV-M3U/main/fr_complete.m3u
  5. Confirmer chargement

Étape 2 : Configurer EPG
  1. Menu ⊙ → Paramètres
  2. Aller à : EPG Source
  3. Cliquer : ADD (Ajouter)
  4. Remplir :
     ┌─────────────────────────────────────┐
     │ URL : xmltvfr.fr/xmltv/xmltv.xml.gz │
     │ Nom : France EPG                    │
     │ Fuseau horaire : Europe/Paris       │
     │ Mise à jour : 6 heures              │
     └─────────────────────────────────────┘
  5. Sauvegarder

Étape 3 : Synchroniser
  1. Menu ⊙ → EPG → Synchroniser
  2. Attendre chargement (1-2 minutes)
  3. Consulter guide : Appui long sur chaîne

✅ RÉSULTAT : EPG complet + 60 chaînes !

⚙️ MAPPAGE TVG-ID (IMPORTANT POUR EPG)
═══════════════════════════════════════════════════════════════════════════════

Pour que l'EPG fonctionne, tvg-id DOIT correspondre entre M3U et EPG.

EXEMPLE :

Dans votre M3U (fr_complete.m3u) :
  #EXTINF:-1 tvg-id="tf1.fr" tvg-name="TF1"...

Dans l'EPG (xmltv.xml.gz) :
  <channel id="tf1.fr">

✓ MÊME ID = EPG fonctionne
✗ ID différent = EPG absent

❓ DÉPANNAGE & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

PROBLÈME 1 : "EPG ne charge pas"
─────────────────────────────────
SOLUTIONS :
  ✓ Vérifier connexion Internet (test : ping 8.8.8.8)
  ✓ Redémarrer lecteur complètement
  ✓ Vider cache app (Paramètres → Stockage)
  ✓ Essayer source alternative (voir ci-dessous)
  ✓ Vérifier URL EPG : https://xmltvfr.fr/xmltv/xmltv.xml.gz
  ✓ Attendre 1-2 min (chargement initial normal)

PROBLÈME 2 : "Pas de programme affiché"
──────────────────────────────────────
SOLUTIONS :
  ✓ Vérifier tvg-id M3U = id EPG (voir section mappage)
  ✓ Forcer actualisation : Menu → Sync EPG Now
  ✓ Attendre mise à jour EPG (peut prendre 2-6 heures)
  ✓ Redémarrer lecteur après synchronisation
  ✓ Vérifier fuseau horaire = Europe/Paris

PROBLÈME 3 : "Erreur XML/Décompression"
──────────────────────────────────────
SOLUTIONS :
  ✓ Essayer version non-compressée :
    https://xmltvfr.fr/xmltv/xmltv.xml
    (Plus lourde mais compatible 100%)
  ✓ Vérifier espace disque disponible
  ✓ Réduire nombre chaînes si possible
  ✓ Contacter support xmltvfr.fr si erreur persiste

PROBLÈME 4 : "Chaîne ne charge pas"
─────────────────────────────────
SOLUTIONS :
  ✓ Vérifier débit Internet : au moins 5 Mbps (speedtest.net)
  ✓ Passer HD → SD (moins consommateur)
  ✓ Redémarrer routeur WiFi (30 secondes)
  ✓ Fermer apps en arrière-plan
  ✓ Connecter en 4G mobile test
  ✓ Essayer autre chaîne pour tester

PROBLÈME 5 : "Fuseau horaire incorrect"
───────────────────────────────────────
SOLUTIONS :
  ✓ Paramètres EPG → Fuseau : Europe/Paris
  ✓ Vérifier heure système (Paramètres → Date & Heure)
  ✓ Activer mise à jour heure auto
  ✓ Redémarrer app après changement

▶ PERFORMANCE & COMPRESSION

  Format GZ vs XML :
    • .gz = 80% réduction taille
    • Chargement 50% plus rapide
    • Utilisé par défaut (recommandé)
    • Support : 99% apps

  Perfect Player :
    Paramètres → EPG → Mise à jour : 6 heures
    Plage horaire : 06:00 - 22:00

  TiviMate :
    Paramètres → EPG → Auto-sync : ON
    Intervalle : 6 heures

    ✓ Télécharger EPG en local

  Ajouter 2 sources EPG :
