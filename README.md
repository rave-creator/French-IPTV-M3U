## 🚀 INSTALLATION RAPIDE

### Perfect Player (Meilleur Option ⭐)

**Étape 1 : Ajouter M3U**
```
1. Ouvrir Perfect Player
2. Menu → Playlist → Ajouter
3. Coller URL M3U ci-dessus
4. Sauvegarder
```

**Étape 2 : Ajouter EPG**
```
1. Menu → Paramètres → EPG Source
2. Ajouter source :
   URL : https://xmltvfr.fr/xmltv/xmltv.xml.gz
   Fuseau : Europe/Paris
3. Sauvegarder
```

**Résultat :** Accès à 60+ chaînes + guide complet ! 📺

---

### TiviMate (Simple)

```
1. Menu → Playlist → Ajouter M3U
2. Paramètres → EPG → Ajouter source
3. URL EPG : https://xmltvfr.fr/xmltv/xmltv.xml.gz
4. Sync et enjoy!
```

---

### VLC (Lecteur Basique)

Média → Ouvrir flux réseau

## 🔧 DÉPANNAGE RAPIDE

### ❌ Chaîne ne charge pas
```
✓ Vérifier connexion Internet (5+ Mbps)
✓ Redémarrer app/lecteur
✓ Vider cache app
✓ Essayer connecté en 4G
✓ Redémarrer routeur WiFi
```

### ❌ EPG absent
```
✓ Vérifier URL EPG valide
✓ Fuseau horaire = Europe/Paris
✓ Attendre chargement (1-2 min)
✓ Forcer actualisation manuelle
✓ Vérifier tvg-id correspondance
```

### ❌ Logos ne s'affichent pas
```
✓ Activer option "Logos" paramètres
✓ Autoriser images externes
✓ Redémarrer app
✓ Vider cache images
```

### ❌ Son/Vidéo saccadé
```
✓ Passer HD → SD
✓ Fermer apps en fond
✓ Redémarrer WiFi
✓ Réduire qualité vidéo
✓ Changer de chaîne test
```
